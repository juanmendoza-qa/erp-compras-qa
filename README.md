\# erp-compras-qa



Pruebas automatizadas del flujo de compras de un ERP: orden de compra, recepción, factura y stock.



\## Sistema bajo prueba



ERPNext v16, levantado en local con Docker.



\## Estado actual



Etapa de estrategia de pruebas. El repositorio todavía no contiene pruebas automatizadas; la estrategia se documentará en `docs/estrategia-de-pruebas.md`.
